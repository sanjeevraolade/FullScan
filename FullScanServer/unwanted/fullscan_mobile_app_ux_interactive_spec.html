Privacy & Telephony Security

Masked Calling Relay & Multi-Number Auto Fallback

To maintain strict candidate data privacy, phone numbers are never displayed in raw text inside the mobile app or native dialer. The app routes calls through a cloud telephony bridge with automated failover retry.

Secure Telephony Handshake & Failover Workflow

STEP 1
Field Executive Taps "Call Primary" or "Call Secondary"
Mobile app issues encrypted request to backend with Case ID: FS-2026-00123. Raw candidate numbers remain hidden (98XXXXXX21 / 97XXXXXX88).
STEP 2
Cloud Telephony Bridge Connects Executive
Telephony server dials executive's registered device and patches to Candidate Primary Phone.
STEP 3
Continuous Multi-Number Failover (If Unreachable)
If Primary number is busy or unreachable, system automatically dials Candidate Alternate Secondary Number (97XXXXXX88) without executive intervention.
STEP 4
Automatic Backend Case Logging
Call duration, timestamps, and connection status are recorded under Case Logs in the backend CRM.
